# Portfolio — Khadija Ibisk

Site personnel : étudiante en Master Ingénierie des Données & IA (Paris Ynov Campus), à la recherche d'un stage Data de 3 mois.

- HTML, CSS et JavaScript purs, sans framework ni étape de build
- Thème clair / sombre, animations au défilement, filtre des projets, réseau de données animé
- Responsive (mobile, tablette, ordinateur) et accessible (navigation clavier, `prefers-reduced-motion`)

## Voir le site en local

Ouvrir `index.html` dans un navigateur, ou :

```bash
python -m http.server 8000
```
